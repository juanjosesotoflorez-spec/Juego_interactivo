Síntesis Teórica para la Exposición:

COBIT 2019 (ISACA): Define el Gobierno (EDM) y la Gestión (APO, BAI, DSS, MEA) tecnológica para asegurar alineación con objetivos estratégicos.

IEEE (IEEE 730 / 12207): Proporciona normas técnicas para el Aseguramiento de Calidad (SQA) y procesos del Ciclo de Vida del Software.

ISO 37000:2021: Guía directiva para el gobierno organizacional, ética, supervisión y toma de decisiones.
